**TerraDart**

As the Dart ecosystem grows — Flutter on the client, more server-side Dart (Firebase Functions, Cloud Run, Cloud Run functions) — teams often still use Terraform for delivery: HCL or `*.tf.json`, alongside the usual GCP console workflows.

TerraDart is my pre-alpha take on type-safe IaC for that stack. Author typed GCP resources in Dart, emit standard `*.tf.json`, and keep your existing `terraform apply` pipeline.

[terradart.dev](https://terradart.dev/) / [GitHub](https://github.com/nozomi-koborinai/terradart) / [pub.dev](https://pub.dev/packages/terradart_codegen)
</div>

**GCP Cost MCP Server**

An MCP server that lets AI assistants like Claude or Cursor estimate GCP running costs — instead of manually using the Google Cloud Pricing Calculator. Built on the Cloud Billing Catalog API with Go + Genkit. Works with conversational requirements and architecture diagrams alike. Adopted for use at the GCP partner company I work for.

[GitHub](https://github.com/nozomi-koborinai/gcp-cost-mcp-server)

**Ableton OSC MCP Server**

An MCP (Model Context Protocol) server that lets AI assistants like Claude or Cursor drive Ableton Live 11+ via AbletonOSC. Built in Go + Genkit. Tracks, MIDI clips, tempo, and clip slots are exposed as MCP tool calls so AI conversation can drive beat-making and music production directly.
